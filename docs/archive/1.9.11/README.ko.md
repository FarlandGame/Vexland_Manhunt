**[Bardiya Alizadeh (Kabir) · Farland_game](https://github.com/FarlandGame)과 [Ali · Alivexor](https://github.com/Alivexor)가 공동 제작한 완전한 Minecraft 러너 대 헌터 경험입니다.**

Vexland_Manhunt는 경기 설정, 팀 역할, 시작 추격, 추적, 진행도, 보상, 결과, 관리 기능을 하나의 Paper 서버 플러그인에 담았습니다. 러너는 엔더 드래곤을 쓰러뜨리려 하고, 헌터는 마지막 러너를 제거하려 합니다. 플러그인은 여러 명의 러너를 지원하며 사망, 리스폰, 차원 이동, 재접속 이후에도 추격이 이어지도록 합니다. 관리자는 `/mhgui` 제어 센터의 메뉴로 경기를 관리할 수 있고, 플레이어는 현지화된 메시지와 안내서를 사용할 수 있습니다.

**1.6.4와 1.9.11은 플러그인 버전 번호입니다.** 제공된 두 빌드는 모두 Minecraft API `1.21.11`과 Java 21 클래스 파일을 선언합니다. 이들은 Minecraft Java Edition용 서버 플러그인입니다. [Paper의 버전별 Java 요구 사항](https://docs.papermc.io/paper/getting-started/)에도 Paper 1.21.11에 Java 21이 명시되어 있습니다. 제공된 설명 파일에는 별도의 플러그인 의존성이 선언되어 있지 않습니다.

이들은 **제작자에게만 부여되는 상위 관리 권한을 포함한 원본 개인 서버 빌드**이며, 제공된 그대로 보존되어 있습니다. 아래 안내서는 공개된 Manhunt 제어 기능을 다룹니다.

## Manhunt 경험

- **러너와 헌터 팀:** 접속 중인 플레이어를 어느 한쪽에 배정합니다. 경기에는 최소 한 명의 러너와 한 명의 헌터 또는 아직 역할이 없는 접속 플레이어가 필요합니다. 팀원이 죽어도 살아남은 러너는 계속 경기를 진행합니다. 사망한 러너는 그 사망으로 경기가 끝나지 않는 한 헌터가 됩니다.
- **영화 같은 경기 시작:** 인벤토리와 게임 모드를 준비하고 팀을 소개한 다음, 룰렛으로 러너의 선행 시간을 정합니다. 이 카운트다운 동안 헌터는 움직일 수 없으며 제목과 소리로 안내를 받습니다. 선행 시간은 무작위이며, 관리자는 헌터를 일찍 풀어 줄 수 있습니다.
- **대상을 선택하는 추적 나침반:** 헌터에게 특수 나침반을 제공합니다. 우클릭하여 대상 메뉴에서 러너를 고르고 추격 중에도 대상을 바꿀 수 있습니다. 서로 다른 차원에 있을 때는 직접 추적이 가능해질 때까지 관련 포털 경로를 따라 추적합니다. 헌터는 리스폰 후 추적기를 다시 받습니다.
- **진행도 표시:** 보스바와 경기 정보는 러너의 장비 및 네더 자원, 블레이즈 막대, 엔더 진주, 엔더의 눈, 요새, 엔드로 이어지는 진행 상황을 반영합니다. 최신 빌드는 더 세분화된 단계와 드래곤 체력을 반영하는 진행도 표시를 추가합니다.
- **러너의 처치 보상:** 진행 중인 경기에서 러너가 헌터를 처치하면, 진행 상황을 반영하는 50개 항목의 가중치 보상 풀을 사용합니다. 추첨 애니메이션, 이중/삼중 보상, 연속 처치 알림, 희귀 아이템 축하 효과를 포함합니다.
- **승리와 결과:** 마지막 러너가 죽으면 헌터가 승리하고, 엔더 드래곤을 쓰러뜨리면 러너가 승리합니다. 경기 종료 제목, 축하 효과, 처치/사망 정보, 임시 아이템 정리가 포함됩니다. 최신 빌드는 MVP, 피해량, 이동 거리 결과도 보여 줍니다.
- **팀 소통과 편의 기능:** `/teammsg`로 팀원에게만 메시지를 보내고, `/trash`로 54칸짜리 아이템 폐기 인벤토리를 열며, `/nv`로 개인 야간 투시를 켜거나 끕니다.
- **메뉴를 통한 관리:** 제어 센터에서 역할, 시작/초기화, 헌터 조기 해제, 아군 피해, 서버 잠금, 전체 순간이동, 회복/허기 충전, 언어, 보호 설정, 상태, 안내서에 접근할 수 있습니다. 동결 기능과 전체 초기화는 다음 경기를 준비하는 데 도움이 됩니다.
- **현지화된 안내서:** 러너, 헌터, 관리자용 책에서 목표, 추적기 사용법, 사망, 설정, 명령어를 설명합니다. 1.9.11에서는 `/mhhelp`로 플레이어의 역할에 맞는 안내서를 제공합니다.
- **Paper Anti-Xray 연동:** 메뉴에서 Paper의 월드 단위 보호 기능을 설정합니다. 변경 사항을 적용하려면 서버를 재시작해야 합니다.

## `/mhgui`를 사용하는 전체 설정 및 사용 안내

### 1. 서버에 빌드 하나 설치하기

**Paper 1.21.11 / Java 21** 서버를 중지하세요. 다운로드한 JAR 중 하나를 `plugins/` 디렉터리에 넣으세요. VexLandManhunt 빌드는 한 번에 하나만 설치하세요. 빌드를 교체한 뒤에는 서버를 완전히 재시작하세요. 플러그인 내부 이름은 `VexLandManhunt`이며 공개 프로젝트 이름은 `Vexland_Manhunt`입니다.

### 2. 제어 센터 열기

**OP** 또는 **`vexland.admin`** 권한이 있는 관리자로 서버에 접속하고 다음을 입력하세요.

```text
/mhgui
```

아래 설명은 플러그인 릴리스 **1.9.11**의 공개 인터페이스를 다루며 영어 버튼 이름을 사용합니다. 버튼 표시는 선택한 서버 언어에 따라 달라집니다. GUI 전체 기능을 사용하려면 신뢰할 수 있는 **OP** 계정을 사용하세요. 설명 파일의 권한은 메뉴를 여는 명령어를 허용하지만, 제공된 일부 GUI 처리기는 더 엄격한 OP 검사를 적용합니다. 주 인벤토리는 9칸씩 5줄로 구성됩니다. 버튼 위에 마우스를 올리면 설명과 현재 설정을 확인할 수 있습니다. 대부분의 버튼은 일반 클릭으로 사용하며, 특수 마우스 동작과 확인 절차는 아래에서 설명합니다. 더 작은 1.6.4 메뉴는 이 절 마지막에 다룹니다.

#### 첫 경기 설정하기

1. **Player Roles(플레이어 역할)**를 여세요. 각 참가자의 플레이어 머리를 클릭하여 표시된 역할을 원하는 값으로 맞추세요. 1.9.11에서 역할은 **Runner(러너)**와 **Hunter(헌터)** 사이를 순환합니다. 아직 역할이 없는 참가자는 첫 클릭에 러너가 됩니다. 좌클릭/우클릭/Shift 클릭이 각각 별도의 역할 선택 단축 동작인 것은 아닙니다. 필요할 때 **Previous Page(이전 페이지)**, **Next Page(다음 페이지)**, **Back to Control Center(제어 센터로 돌아가기)**를 사용하세요.
2. 최소 한 명의 러너와 한 명의 헌터를 배정하세요. 시작 과정에서 아직 역할이 없는 나머지 접속 플레이어를 헌터로 바꿀 수 있으므로, 참가자 전원을 직접 배정하면 팀 구성이 분명해집니다.
3. **Friendly Fire(아군 피해)**를 클릭하여 팀원끼리 피해를 줄 수 있는지 정하세요. 클릭 후 ON/OFF 표시를 확인하세요.
4. **Language(언어)**를 클릭하여 서버 전체 언어를 선택하세요. 이 설정은 자신의 플레이어만이 아니라 모든 사람의 메시지, 인터페이스, 알림, 안내서에 영향을 줍니다.
5. **Smart Hunter Kit(스마트 헌터 장비 세트)**, **Auto World Spawn(자동 월드 스폰)**, **Anti-Cheat(부정행위 방지)**를 검토하세요. 게임 안에서 설명이 필요하면 책 버튼의 관리자 안내서를 읽으세요.
6. **Server Freeze(서버 동결)**가 꺼져 있는지 확인한 뒤 **Start Match(경기 시작)**를 클릭하세요. 시작 과정은 플레이어와 인벤토리를 준비하고, 소개와 무작위 헌터 대기 시간 룰렛을 진행한 다음 추격을 시작합니다. 시작 전에 보관할 물건은 참가자 인벤토리 밖으로 옮겨 두세요.

#### 역할과 선택한 대상

**Player Roles(플레이어 역할)**는 참가자의 실제 Manhunt 팀을 바꿉니다. 플레이어 머리를 클릭하고 갱신된 역할을 확인하세요. STARTING/RUNNING 중에는 러너/헌터 변경을 허용하지만 마지막 러너를 헌터로 바꾸는 것은 거부합니다. 이렇게 진행 중인 경기의 러너 진영을 유지합니다. 변경 후 팀 실행 상태와 추적기가 동기화되므로 역할 변경은 의도적으로 사용하세요.

**Target Player(대상 플레이어)**는 별도 기능입니다. 팀을 바꾸지 않고 Freeze Target, Clear Target Inventory, Kill Target 같은 작업의 대상을 선택합니다. 원하는 접속 플레이어의 이름이 표시될 때까지 순환 선택하세요. 저장된 대상이 사용할 수 없게 되면 코드가 다른 접속 플레이어 중 첫 번째로 대상을 바꿀 수 있으므로, 선택 대상 작업 직전에 반드시 이름을 확인하세요. 다른 플레이어가 접속해 있지 않으면 사용할 수 있는 대상이 없다고 알립니다.

**Clear Target Inventory(대상 인벤토리 비우기)**와 **Kill Target(대상 죽이기)**는 **5초** 이내에 같은 대상에 대해 같은 작업을 두 번 클릭해야 합니다. 첫 클릭은 확인을 준비하고 대상을 알리며, 두 번째 클릭은 작업을 실행합니다. 대상을 바꾸거나 너무 오래 기다리면 확인을 다시 해야 합니다. 인벤토리를 비우면 내용물이 삭제되고, 러너를 죽이면 일반 사망 규칙에 따라 경기가 끝나거나 달라질 수 있습니다.

**Freeze Team(팀 동결)**은 이 메뉴에서 유일하게 팀별 마우스 단축 동작을 사용하는 기능입니다. 일반 좌클릭은 러너 팀을, 일반 우클릭은 헌터 팀을 선택하고, Shift 클릭은 이 도구가 관리하는 모든 개별/팀 동결을 해제합니다. 전체 Server Freeze 스위치는 별도 제어이므로, 플레이어가 계속 동결되어 있으면 따로 꺼야 합니다.

#### Smart Hunter Kit(스마트 헌터 장비 세트)

**Smart Hunter Kit**를 클릭하여 적응형 헌터 리스폰 장비 세트를 켜거나 끕니다. 버튼에는 현재 상태가 표시됩니다. 켜져 있으면 리스폰하는 헌터가 러너 장비와 경기 상황에 맞춘 장비 세트를 받을 수 있습니다. 제공된 플레이어 안내서는 이를 러너 평균보다 약한 장비 세트라고 설명합니다. 꺼져 있으면 헌터는 사망 후 자동 장비 세트를 받지 않습니다. 추적 나침반은 꺼지지 않습니다.

상태를 전환하는 대신 직접 설정하려면 `/mhkit on`, `/mhkit off`, `/mhkit status`를 사용하세요. 확인한 새 설정의 폴백 기본값은 켜짐입니다.

#### Auto World Spawn(자동 월드 스폰)

**Auto World Spawn**을 클릭한 뒤 **OFF(끄기)**, **5 minutes(5분)**, **10 minutes(10분)**, **15 minutes(15분)**, **20 minutes(20분)**, **30 minutes(30분)** 중 하나를 고르세요. 옵션을 선택하면 저장하고 `/mhgui`로 돌아갑니다. **Back(뒤로)**은 새 간격을 선택하지 않고 돌아갑니다.

활성화하면 시스템이 주기적으로 활동 중인 오버월드 러너 근처의 안전한 오버월드 지표면을 찾고, 그곳으로 월드 스폰을 옮깁니다. 오버월드에 러너가 없거나 안전한 후보 위치를 찾지 못하면 이동을 건너뜁니다. 새 설정의 폴백 기본값은 꺼짐입니다. 명령어로 같은 제어를 하려면 `/mhspawn off`, `/mhspawn 15`, `/mhspawn status`를 사용하고, 15 대신 지원되는 다른 간격을 입력하세요.

#### 일시 정지, 재접속, 복구

경기가 RUNNING 상태일 때 **Pause Match(경기 일시 정지)**를 사용할 수 있습니다. 게임 시스템, 이동/상호작용, 경기 타이머, 추적, 스폰 이동을 멈춥니다. **Resume Match(경기 재개)**는 이러한 시스템을 재개하고 일시 정지한 시간을 보정합니다. Server Freeze는 플레이어만 동결하므로, 경기 시계를 멈춰야 할 때 대신 사용하면 안 됩니다.

러너의 재접속 허용 시간을 설정할 수 있으며, 새 설정의 폴백 기본값은 **15분**입니다. 시간 안에 다시 접속하면 러너 상태를 복원하고 10초 동안 재입장 보호를 제공합니다. 서버 중단 시간은 저장된 재접속 시간을 소비하지 않습니다. 시간이 만료된 러너 자리는 헌터로 전환되며, 마지막 러너의 시간이 만료되면 헌터가 승리할 수 있습니다.

**제공된 1.9.11 GUI에는 별도의 재접속 시간 선택기가 없습니다.** 값을 바꾸려면 서버를 중지하고 `plugins/VexLandManhunt/config.yml`을 편집하세요. 다른 설정은 유지하고 다음과 같이 설정하세요.

```yaml
features:
  custom-reconnect-minutes: 15
```

편집 후 재시작하세요. 1분 미만의 값은 1분으로 제한됩니다. **Reset Settings(설정 초기화)**는 이 값을 15분으로 복원합니다. 컴파일된 빌드는 서버 재시작/충돌 후 복구를 위해 경기/재접속 상태와 백업 스냅샷도 저장합니다. 플레이 중 이러한 파일을 직접 편집하지 말고 플러그인이 관리하도록 두세요.

#### Reset Settings(설정 초기화)와 Reset Match(경기 초기화)

**Reset Settings**는 **8초** 이내에 버튼을 두 번 클릭해야 합니다. 첫 클릭은 확인을 준비하고, 두 번째 클릭은 **Smart Kit 켜짐**, **자동 스폰 15분 간격**, **재접속 15분**, **무작위 선행 시간**을 복원합니다. 이는 Auto World Spawn의 폴백 기본값이 꺼짐인 새 설치와 다릅니다. 이 기능은 설정을 바꾸며 전체 경기 초기화를 대체하지는 않습니다.

**Reset Match**는 기존의 경기 초기화를 수행합니다. 임시 경기 상태/아이템을 정리하고 다음 라운드를 위해 플레이어를 오버월드 스폰으로 돌려보냅니다. 주 버튼은 Reset Settings의 두 번 클릭 확인을 사용하지 않습니다. **Start Match**는 참가자 인벤토리를 준비하거나 비울 수 있습니다. 클릭 전에 어떤 초기화/시작 제어를 사용할지 확인하세요.

#### 언어와 부정행위 방지 제어

**Language(언어)**는 전체 서버 언어 선택기를 엽니다. 원하는 언어의 이름을 클릭하세요. 제공된 두 빌드에는 영어, 페르시아어, 아랍어, 스페인어, 프랑스어, 독일어, 러시아어, 중국어 간체, 힌디어, 포르투갈어가 포함됩니다. 선택한 언어는 서버 전체에서 공유되고 저장됩니다. 일본어 README 문서는 플러그인의 게임 내 선택기에 일본어를 추가하지 않습니다.

**Anti-Cheat(부정행위 방지)**는 **VexAC Security**를 엽니다. **VexAC Master**를 클릭하여 내부 엔진을 켜거나 끄고, **Movement**, **Combat**, **AutoClick**, **Velocity / AntiKB**, **World / Scaffold**를 클릭하여 해당 그룹을 켜거나 끌 수 있습니다. **Anti X-Ray**는 Paper에 설정된 Anti-Xray를 켜거나 끕니다. 이 변경을 적용하려면 서버를 재시작하세요. 상태, 증거 로그, 탐지 모델 타일에서 현재 시스템을 설명합니다. **Back to Control Center(제어 센터로 돌아가기)**는 주 메뉴로 돌아갑니다.

이 빌드의 인터페이스는 제재 방식을 모니터링 전용이라고 설명하지만, 정적 검사에서는 임계값에 따른 강퇴 경로가 여전히 남아 있습니다. 메뉴의 강퇴 없음 문구를 구현과 문서의 불일치로 보고, 이를 신뢰하기 전에 통제된 서버에서 제재 동작을 확인하세요.

#### 게임 내 안내서와 문제 해결

**Manhunt Administrator Guide(Manhunt 관리자 안내서)**를 클릭하거나 `/mhhelp`를 사용하여 현지화된 안내서를 받으세요. 1.9.11에서는 플레이어가 `/mhhelp`로 자신의 역할에 맞는 안내서를 받을 수 있습니다. 헌터는 나침반을 우클릭하여 러너를 선택합니다. 이 추적기 인터페이스는 관리자의 Target Player 선택기와 별개입니다.

역할이나 추적기가 동기화되지 않은 것 같으면 **Emergency Sync(긴급 동기화)**가 관련 실행 상태를 갱신합니다. **Match Info(경기 정보)**로 현재 팀과 상태를 확인할 수 있습니다. 시작 요청이 실패하면 경기가 준비되어 있는지, 서버 동결이 꺼져 있는지, 러너/헌터 팀이 존재하는지 확인하세요. JAR를 바꾼 뒤에는 `/reload` 대신 서버를 완전히 재시작하세요. `/mhdebug`는 1.9.11에 포함된 관리자 진단 명령어입니다. 이 명령어가 있다고 해서 해당 릴리스가 실제 서버 테스트를 통과했다는 뜻은 아닙니다.

#### 이전 1.6.4 제어 센터 사용하기

1.6.4에는 **Player Roles**, **Friendly Fire**, **Start Match**, **Reset Match**, **Release Hunters Now**, **Server Lock**, **Teleport Everyone To Me**, **Heal & Feed Everyone**, **Match Status**, 언어 선택, **Anti Cheat**, 관리자 안내서가 유지됩니다. 역할은 **None → Runner → Hunter** 순서로 순환하며, 경기를 시작 중이거나 진행 중일 때 역할을 바꿀 수 없습니다.

부정행위 방지 메뉴에는 구형 **Anti AutoClick**(경고/강퇴 처리가 있는 30-CPS 규칙), **Anti Fly**, Paper **Anti X-Ray**가 포함됩니다. 러너의 재접속 허용 시간은 **60분**으로 고정되어 있습니다. 위에서 설명한 새로운 Smart Hunter Kit V3 스위치, Auto World Spawn 선택기, 일시 정지/재개, Reset Settings 확인, 확장된 선택 대상/월드 도구는 1.9.11의 기능이므로 이전 메뉴에 있을 것으로 기대하면 안 됩니다.

이 안내서는 제공된 JAR 메타데이터, 포함된 언어/도움말 텍스트, 정적 디스어셈블을 바탕으로 작성했습니다. 이번 검사에서는 실제 Minecraft 서버에서 인터페이스를 실행하지 않았습니다.

### 3. 추격 플레이하기

러너는 무작위 선행 시간 동안 도망가고 엔더 드래곤을 쓰러뜨리기 위해 진행합니다. 헌터는 해제를 기다린 뒤 추적 나침반을 우클릭하여 러너를 선택합니다. 플레이 중에는 추격이 차원을 넘을 때를 포함해 대상을 바꿀 수 있습니다. `/teammsg <message>`로 자신의 팀에게만 말하고, 1.9.11에서는 `/mhhelp`로 현지화된 역할 안내서를 받으세요.

러너가 죽으면 나머지 러너는 계속 플레이하고 사망한 플레이어는 헌터가 됩니다. 헌터는 리스폰하여 계속 추적할 수 있습니다. 마지막 러너의 사망이나 러너 접속 종료 허용 시간 만료는 헌터의 승리로 경기를 끝낼 수 있고, 엔더 드래곤을 쓰러뜨리면 러너의 승리로 끝납니다.

### 4. 일시 정지, 종료, 다음 경기 준비하기

1.9.11에서는 `/mhpause`로 일시 정지하고 `/mhresume`으로 계속 진행합니다. 선행 시간 카운트다운이 끝나기 전에 헌터를 풀어 주려면 `/mhrelease`를 사용하세요. 새 경기를 위해 제어 센터의 전체 초기화 또는 `/mhreset`을 사용하세요. 초기화는 임시 경기 상태와 아이템을 정리하고 플레이어를 오버월드 스폰으로 돌려보냅니다. Paper Anti-Xray 설정을 바꾸려면 재시작이 필요합니다.

## 1.9.11 기본 설정

확인한 새 설정의 폴백 기본값은 다음과 같습니다.

```yaml
features:
  adaptive-hunter-kit: true
  auto-world-spawn-minutes: 0
  custom-reconnect-minutes: 15
```

`0`은 자동 스폰 이동이 꺼져 있음을 뜻합니다. 반면 GUI의 확인된 설정 초기화 작업은 스폰 간격을 15분으로 설정합니다. 해당 설정은 GUI 또는 `/mhkit`과 `/mhspawn`으로 관리하세요.

## 게임 내 언어와 문서 언어

제공된 두 빌드에는 **10개의 게임 내 언어**가 있습니다. 영어, 페르시아어, 아랍어, 스페인어, 프랑스어, 독일어, 러시아어, 중국어 간체, 힌디어, 포르투갈어입니다. 관리자는 `/mhlang`으로 **전체 서버 언어**를 선택합니다. 메시지, 메뉴, 알림, 안내서는 이 선택을 사용하며, 선택한 값은 `language.txt`에 저장됩니다.

GitHub 문서는 **아랍어 문서판을 제외한 18개 언어**로 게시되고 있습니다. 일본어, 터키어와 그 밖에 추가된 README 번역은 독자가 프로젝트를 이해하도록 돕습니다. 이 원본 JAR에 새로운 게임 내 언어를 추가하는 것은 아닙니다.
